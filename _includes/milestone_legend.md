## Milestones
{: .no_toc }

- **Shipped (✓ X.Y.Z)** — implemented today, delivered in the version shown.
- **1.0.0-beta.N (Beta)** — shipped prerelease under functional, operational, and scale validation.
- **1.0.0 (MVP/GA)** — the first stable release scope: production-ready, commercially supportable.
- **1.1.0, 1.2.0, …** — planned post-GA feature batches; ordered where the product's roadmap states an order, otherwise unordered (see **[Milestones & Versions]({% link milestones.md %})**).
- **Unversioned** — exploratory / research-tier; may never ship.

Milestones express prioritization and implementation reality — **not delivery commitments or dates**. The canonical vocabulary, version semantics, and per-product version milestones live on the **[Milestones & Versions]({% link milestones.md %})** page.
