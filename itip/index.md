# ITIP — the IT Intelligence Platform

{: .no_toc }

The **IT Intelligence Platform (ITIP)** is the first domain application built on **[SIE]({% link sie/index.md %})**. It is where all IT profiles converge — architects, developers, ops engineers, project managers, security officers, compliance analysts — to define, govern, regulate and supervise the IT landscape through a single governed source of truth.

From that truth, ITIP generates IT artifacts, simulates impacts, and evaluates compliance against any governance or regulatory framework sourced into **[GSM]({% link gsm/index.md %})**.

## Products

- **[Web Application]({% link itip/web-application/index.md %})** — the application every IT profile works in, for defining, governing, regulating, and supervising the IT landscape. Start with **[Getting Started]({% link itip/web-application/getting-started.md %})**, then **[General Usage]({% link itip/web-application/general-usage.md %})** and the role-specific **[Usage Scenarios]({% link itip/web-application/usage-scenarios/index.md %})**.
- **[Definition Blackboard Code Sourcer]({% link itip/definition-blackboard-code-sourcer/index.md %})** — truth sourcing, so IT information reflects reality continuously as GSM Definitions. *Documentation in construction.*
