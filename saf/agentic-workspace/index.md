# Agentic Workspace

{: .no_toc }

> **In construction.** This product's documentation is being written.

The **Agentic Workspace** is the shared remote workspace of the Systemic Agentic Framework: it stores the artifacts produced by local agentic workflows — Epics, Features, Stories, ADRs, kanbans and gate records — and carries them out to your organization's central systems. The local filesystem blackboard stays the working surface; the workspace is where committed artifacts become the organization's shared state.
